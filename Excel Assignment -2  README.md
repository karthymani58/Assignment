# Excel Data Cleaning & Processing Assignment

## Project Overview
This repository contains a cleaned, structured, and standardized dataset derived from raw multi-task Excel files. The data transformations address missing values, text standardization, delimiter parsing, date formatting, and conditional formatting.

## Repository Files

* `Final_Cleaned_Dataset.xlsx` - Master Excel workbook containing all completed tasks and clean datasets.
* `assignment-docs/` - Folder containing original task PDF instructions.

## Summary of Completed Tasks

* **Task 1 (Missing Values):** Filled missing price entries using category average formulas.
* **Task 2 (Text Standardization):** Fixed incomplete text strings using Find & Replace (e.g., `Electroni` to `Electronics`).
* **Task 3 (Delimiter Setup):** Split combined codes using *Text to Columns* with custom hyphens[cite: 6].
* **Task 4 (Date & Currency):** Standardized dates into `DD-MM-YYYY` using `DATEVALUE` and applied currency formatting (`$`).
* **Task 5 (Conditional Formatting):** Highlighted category-specific records using custom conditional formatting rules.
