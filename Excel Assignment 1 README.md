# Excel Assignment 1: Data Exploration

## Project Overview
This repository contains Excel assignment focused on data manipulation, extraction, and conditional logic. The goal was to analyse a product dataset and extract structured details using built-in Excel functions.

## Key Tasks Completed

### 1. Descriptive Statistics
* Calculated the **Total Price** of all products using `SUM`.
* Counted the total number of products using `COUNTA`.
* Determined the **Average, Minimum, and Maximum** product prices using `AVERAGE`, `MIN`, and `MAX`.

### 2. Logical & Conditional Functions
* **IF Function:** Created a `Price Range` column to categorize products priced at **$500** or higher as 'High Price'.
* **SUMIF Function:** Calculated the total price specifically for items in the **Electronics** category.
* **COUNTIF Function:** Counted the total number of products priced under **$100**.

### 3. Text Extraction
Extracted codes from the `Product ID` column using text formulas:
* **LEFT:** Extracted the first 2 characters to create a **Day** column.
* **MID:** Extracted the 4th to 6th characters to create a **Month** column.
* **RIGHT:** Extracted the last 2 characters to create a **Country Code** column.
